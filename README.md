## 🚀 What is ShopFlow API?

**ShopFlow Backend** is a highly scalable RESTful API built with Node.js and Express. It powers the ShopFlow e-commerce platform by handling everything from secure authentication and product management to complex order processing and payment integrations.

---

## ✨ Core Features

| Feature | Description |
| :--- | :--- |
| 🔐 **Authentication** | Secure JWT-based user authentication and authorization |
| 📦 **Product Management** | CRUD operations for products, categories, and inventory |
| 🛍️ **Order Processing** | Complete lifecycle management for customer orders |
| 🛡️ **Security** | Rate limiting, data sanitization, and helmet integration |
| 💳 **Payments** | Integration ready for Stripe/PayPal gateways |

---

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB & Mongoose
- **Security:** JSON Web Tokens (JWT), bcryptjs

---

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mhassannaseerahmed-arch/shop-flow-backend.git
   cd shop-flow-backend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Environment Setup:**
   Create a `.env` file based on `.env.example` and add your MongoDB URI and JWT secret.

4. **Run development server:**
   ```bash
   npm run dev
   ```
